## 📁 Projects

- **Tab Manager** (*React, Next.js, TypeScript, Chrome Extension API, MongoDB, Tailwind CSS*) <br> Developed a tab management tool that integrates a web application with a Chrome extension using a custom-built messaging system and API. The tool allows users to organize their tabs and bookmarks into ‘workspaces’, each dedicated to a specific project or focus area. Workspaces are automatically synced to the cloud, and users can seamlessly open, close, and switch between them with a single click, even from another device.

- **Bug Tracker** (*Python, Flask, SQLite*) <br>
A project and task management web application with a role-based access control and team hierarchy, featuring Kanban boards and Gantt charts for progress visualization, a commenting system, and more, allowing efficient team collaboration and productivity.<br>

- **Shift Tracker** (*Java, Android SDK, Firebase, Android Studio*) <br>
An Android application designed to help teenagers track their work shifts and income. Featuring job and shift management through CRUD operations, reminder notifications for upcoming shifts, real-time shift tracking, data visualization, and exporting data to Excel.

- **AI-Powered English Coach** (*React, TypeScript, OpenAI API*) <br>
A web application that enables users to engage in an interactive voice conversation with AI, designed to improve their English speaking skills and grammar through personalized feedback. The app converts the user’s recorded speech to text and sends it to GPT-3 to generate a response, which is delivered to the user in a text-to-speech format.

- **Trading Platform** (*Python, Flask, SQLite, IEX Cloud API*) <br>
Developed the back-end of a stock trading platform that includes portfolio management, buying and selling stocks with real-time price quotations using IEX Cloud API, and calculating profits.
